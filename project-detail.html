Space Ship

Unity 6 • C# • 2D Arcade Space Shooter
Space Ship 2D is a complete retro-inspired arcade space shooter developed as a solo project using Unity 6 and C#. The game features three distinct playable stages, escalating multi-phase boss encounters, dynamic enemy AI swarms, inventory and weapon systems, particle FX, and optimized bullet-hell mechanics powered by high-frequency Object Pooling and detailed profiling.
View Source Code Play on Itch.io

Gameplay Features

  • Responsive Flight Controls: Smooth spaceship navigation with directional thrusters, mouse targeting, and precision dodging.
  • Three Playable Stages: Handcrafted levels with progressive enemy wave density, environmental hazards, and unique pacing.
  • Multi-Phase Boss Battles: Complex boss encounters featuring phase transitions, distinct bullet attack patterns, and shield mechanics.
  • Dynamic Enemy AI: Adaptive enemy flight paths, formation tracking, and targeted projectile firing.
  • Inventory & Item Drops: In-combat pickups for energy regeneration, explosive ordnance, and shield repair.
  • Audio & Visual Feedback: Custom laser SFX, camera shake impact, screen flashes, and particle engine explosions.

Technical Architecture

  • Object Pooling Architecture: Pre-instantiated projectile, enemy, and VFX pools to completely eliminate GC allocations during intense bullet-hell gameplay.
  • Modular Enemy State Machines: Clean C# state transitions controlling patrolling, chasing, charging, and special boss attacks.
  • ScriptableObject Configurations: Data-driven weapon parameters, enemy wave profiles, and stage settings for rapid balancing.
  • Custom Spawner Logic: Timed and trigger-based spawning algorithms with randomized spawn node offsets.
